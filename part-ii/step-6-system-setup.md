# Step 6: System setup

#### Required Downloads

Before continuing, make sure to download and install the following:

* 📁 **WinRAR**
* 🎮 **DirectX Runtime**
* 🧱 **Visual C++ Runtimes (All-in-One)**
* 📁 **Dcontrol**

{% hint style="danger" %}
Make sure to unplug your USB Drive!
{% endhint %}

#### Download the Compatibility Checker

Download the Compatibility Checker and ensure that both Wi-Fi and Bluetooth are either **disabled** or showing as **Unknown**.
